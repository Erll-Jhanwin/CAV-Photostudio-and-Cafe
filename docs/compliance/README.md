# Assurance evidence index

This directory contains implementation evidence and operational templates for the ISO/IEC/IEEE 23026:2023, WCAG 2.0, ISO/IEC 27001:2022, and ISO/IEC 27701:2025 remediation program.

Code controls are verified by the repository checks and tests. Organizational controls remain subject to approval, assignment, records, and periodic review. These documents do not represent a certification claim.

- `isms-scope-risk-register.md` — ISMS scope, assets, risks, owners, and treatment tracking.
- `privacy-record-of-processing.md` — PII inventory, lawful basis, processors, retention, and transfers.
- `privacy-impact-assessment.md` — PIA/DPIA worksheet and approval gates.
- `incident-response.md` — detection, triage, containment, notification, and lessons learned.
- `backup-disaster-recovery.md` — backup, restore testing, RPO/RTO, and recovery evidence.
- `supplier-security-review.md` — supplier due diligence and contract evidence.
- `release-maintenance.md` — ownership, release, rollback, monitoring, and maintenance procedures.
