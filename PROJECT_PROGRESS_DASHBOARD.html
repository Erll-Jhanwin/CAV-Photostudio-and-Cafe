Scoring method and scope

Use this section when comparing future dashboard snapshots.

Implementation score: each module receives a progress score based on source code, API routes, UI wiring, automated tests, and direct verification. The module score is multiplied by its stated weight; weights sum to 100. A coded feature without an exposed user path, a required external dependency, or test evidence receives partial credit. A placeholder app or missing workflow receives low or zero credit.

Not counted as proof: architecture prose, filenames alone, seeded data alone, or an unexecuted deployment plan. The report does not change application code, migrations, database contents, or runtime behavior.
